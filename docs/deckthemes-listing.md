# DeckThemes listing — Slate

Text for the DeckThemes submission form (copy-paste). Images: the eight 1280×800 screenshots kept
locally in `docs/screenshots/preview/` (not in the repo); `1-home.png` first.

**Name:** Slate

**Target:** System-Wide

**Version:** v1.0.0

**Short description** (same as `theme.json`):
> A minimal, clean Gaming Mode theme: neutral charcoal, rounded shapes and calm Slate accents. The
> games are the artwork; the interface disappears.

**Long description:**

Slate turns Gaming Mode into a quiet, neutral frame for your games. Steam's navy and blue-grey surfaces
become soft charcoal, square corners become rounded, and Steam's bright blue and green accents become
calmer Slate blue and green. Colours that carry information stay as they are: ProtonDB tiers, review
scores, warnings, sale branding and Deck compatibility.

Covers every screen CSS Loader can reach:
- Home: full-screen Recent Games with larger covers and faded hero art (or Steam's compact hero)
- Library, game pages, Search, Media, Downloads
- Settings and Game Properties
- Store: home, game pages, search, categories, wishlist
- STEAM menu and in-game pages (Achievements, Guides, Notes), Quick Access, Friends & Chat
- Context menus, notifications and toasts, the on-screen keyboard

Options (CSS Loader › Slate):
- **Hero:** Full (default): Recent Games fills the screen · Compact: Steam's hero height
- **Keyboard:** Slate (default) · Steam (turns keyboard theming off)

Works with protondb-decky and playcount-decky badges. The controller layout editor can't be themed
(CSS Loader can't reach it).

Tested on Steam Deck LCD with SteamOS 3.9.5 (stable) and 3.9.6 (beta), CSS Loader 2.1.3. OLED and
docked displays are untested.

Source, changelog and selector notes: https://github.com/rrambul/slate-steam-deck (MIT)
